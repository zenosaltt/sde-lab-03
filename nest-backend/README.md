# Backend NestJS

Istruzioni di avvio, modello dati, esempi `curl` e scaletta didattica sono nel [README principale](../README.md). Dalla radice del repository, `./start-lab.sh` avvia backend, MySQL e Redis in Docker e inserisce i dati mancanti. Le modifiche a questa directory sono visibili nel container; NestJS ricompila automaticamente le modifiche ai sorgenti.
